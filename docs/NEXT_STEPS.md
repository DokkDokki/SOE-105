## 1. Push to GitHub

**Settle this first — the repo contains Mitsubishi's data.**

`data/raw/` holds `Sale Order History.xlsx` (272,000 real order lines), `Item.xlsx`
and `Customer.xlsx`. The records are anonymised (`AAA CO.,LTD.`, item code `AAB`),
but they are still Mitsubishi's commercial sales figures — real quantities, real
prices, real revenue totals. Pick one before pushing:

| Option | Effect |
|---|---|
| **Private repo** | Everything is preserved, visible only to invited collaborators. Simplest. |
| **Public repo + `.gitignore data/raw/`** | Code and documentation are shareable; whoever clones it supplies their own data files. |
| **Public repo including data** | Only if Mitsubishi has explicitly agreed the data may be published. Assume they have not. |

The project is not yet a git repository — it needs `git init` first.

Also worth excluding regardless of choice: `outputs/dashboard_bundle.pkl` (~38 MB)
and `outputs/backtest_all_models_scored.csv` (~15 MB). Both are regenerated by
`python run_pipeline.py` in about two minutes.
